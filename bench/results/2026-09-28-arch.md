## Download time

Each run downloads into an empty cache, including an empty Xet chunk cache. *No Xet* sets HF_HUB_DISABLE_XET so huggingface_hub uses plain HTTP. *Cold* is a fresh hub pulling from upstream while it packs; *warm* is the same hub serving from its store.
